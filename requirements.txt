# The mkl pin is the fix for:
#   ImportError: .../torch/lib/libtorch_cpu.so: undefined symbol: iJIT_NotifyEvent
# iJIT_NotifyEvent is an Intel ITT profiling symbol. MKL 2024.1 and later stopped
# exporting it, while libtorch_cpu.so still expects it. Pinning MKL back to
# 2024.0.0 restores the symbol. Keep this pin ABOVE torch.
mkl==2024.0.0
